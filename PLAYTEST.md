# Playtest checklist

## MVP flow
- [x] Start screen shows the game title.
- [x] Player can enter a company name and incident lead name.
- [x] Team roster and initial status are visible.
- [x] A decision can be made at each landmark.
- [x] Resource values change based on the decision.
- [x] The incident advances through the landmark sequence.
- [ ] An illustrated incident report appears after each decision.
- [ ] Each music track and the off option can be picked on the title screen.
- [ ] The intern coffee run is playable, fair, and the Rush Hour music plays during it.
- [x] The game resolves to a clear outcome: contained, breached, team collapsed, fired, or bankrupt.

## Quality checks
- [x] The game remains readable and stable at a 640x480 layout.
- [ ] The flow is understandable without extra explanation.
- [x] The project remains simple and free of unused complexity.
- [x] The test suite still passes after changes.
- [ ] Sound effects and music are audible and fit the theme.
- [ ] A thoughtful player usually wins; a careless one usually loses.
